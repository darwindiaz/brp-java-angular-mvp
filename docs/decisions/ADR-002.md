# ADR 002 Política de acceso

**Estado:** aprobado para la autorización contextual. La duración del token y la cardinalidad de roles son supuestos. **Requisitos:** DA-04, RS-01 a RS-05 y RF-08.

**Contexto.** La interfaz debe reflejar permisos del servidor y la retirada de un módulo debe poder hacerse efectiva mientras un JWT siga vigente.

**Alternativas.** Permisos completos dentro del JWT o identidad en el JWT y consulta de acceso vigente.

**Decisión.** Autorización por rol, módulo y contexto de oferta. El diseño usa JWT para identidad y resuelve permisos vigentes en servidor. La política de capacidades se comparte con el inicio de Angular.

**Consecuencias.** Una lectura de permisos por solicitud permite aplicar retiros y cambios de rol sin esperar el vencimiento. Los listados, detalles y adjuntos deben aplicar el alcance efectivo.
