# ADR 002 Política de acceso

**Estado:** aprobado. Un rol por usuario y JWT de 15 minutos para el MVP. **Requisitos:** DA-04, RS-01 a RS-05 y RF-08.

**Contexto.** La interfaz debe reflejar permisos del servidor y la retirada de un módulo debe poder hacerse efectiva mientras un JWT siga vigente.

**Alternativas.** Permisos completos dentro del JWT o identidad en el JWT y consulta de acceso vigente.

**Decisión.** Autorización por rol, módulo y contexto de oferta. El diseño usa JWT para identidad y resuelve permisos vigentes en servidor. La política de capacidades se comparte con el inicio de Angular.

**Consecuencias.** Una lectura de permisos por solicitud permite aplicar retiros y cambios de rol sin esperar el vencimiento. Los listados, detalles y adjuntos deben aplicar el alcance efectivo.

**Implementación de identidad.** Spring Security valida un JWT HS256 con
emisor y audiencia fijos y clave externa. El JWT contiene identidad y fechas.
El backend obtiene el rol y los módulos de PostgreSQL. No hay refresh ni
revocación individual. La cuenta inactiva se rechaza al autenticar el token.
El servicio administrativo vuelve a evaluar los permisos después de
adquirir el bloqueo transaccional común antes de modificar una cuenta.

El decodificador exige `iat` y `exp`, permite cinco segundos de adelanto
en `iat` y rechaza vigencias que exceden 900 segundos. Expiración exige
`now < exp` sin tolerancia. Salud y login
comparten la cadena de seguridad y quedan excluidos de la lectura Bearer.
El limitador usa memoria local y aplica un cupo por IP y otro global en
una ventana fija. Al cruzar el corte pueden acumularse ráfagas de dos
ventanas consecutivas. La IP se obtiene de la conexión sin usar
`X-Forwarded-For` directamente. Si el servidor recibe la IP de un proxy,
sus usuarios comparten el cupo. Antes de desplegar detrás de un proxy o
balanceador, se debe configurar una cadena de proxies de confianza que
sanee los encabezados reenviados o limitar en el gateway. Un despliegue
multinodo requiere un limitador compartido o un gateway.
